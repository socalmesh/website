The site uses one font: Inter (latin characters only), stored here as
inter-latin-variable.woff2 so no request goes to anyone else's server.

Inter is licensed under the SIL Open Font License 1.1 — the licence text is in
inter-OFL.txt in this folder, and it must stay with the font file.

The @font-face rule that uses this file is in src/layouts/BaseLayout.astro.
